# Contributing Guidelines

Thank you for contributing to this repository.
This document outlines the standards, tools, and approval processes required to maintain consistency, quality, and compliance across all enterprise projects.

---

## Overview

All contributions (code, documentation, or configuration) must:

- Comply with organization-wide **security**, **compliance**, and **coding standards**.
- Pass all **automated checks** in GitHub Actions.
- PRs should be reviewed and approved according to the **CODEOWNERS** policy.

---

## Prerequisites

- Ensure you setup the [Git Credential Manager](GIT_CREDENTIAL_MANAGER.md).
- Ensure you have access to this Repository.
- Ensure you clone the git repo and install the [pre-commit hooks](GIT_PRE-COMMIT_HOOKS.md)

## Security

- Do not commit secrets or private keys.
- Report security issues per [SECURITY.md](SECURITY.md).

We appreciate your contributions and efforts to keep the automation reliable and secure!
